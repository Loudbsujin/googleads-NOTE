# 테스트 데이터 폴더

이 폴더에 디버깅용 테스트 파일을 넣어주세요.

## 1. 구글 애즈 내보내기 파일

- 구글 애즈에서 내보낸 `.csv` 또는 `.xlsx` 파일을 그대로 업로드
- 캠페인별로 나뉜 파일이면 여러 개를 함께 넣어도 됩니다
- 파일 형식은 자동 인식합니다 (UTF-16LE/UTF-8, 탭/콤마 구분 모두 지원)

## 2. 정답지: 구글 애즈 전체 실적 표

디버깅의 핵심입니다. 구글 애즈 대시보드 상단에 보이는 **합계 수치**를 적어주세요.
아래 형식으로 `expected.md` 같은 파일을 만들어 함께 넣어주시면 가장 좋습니다.

```
기간: 2026-01-01 ~ 2026-06-05
캠페인 수: 15

노출수: 385,562
비용: JP¥111,404
조회수(TrueView 조회수): ___
클릭률(CTR): 0.20%
전환수: 1,443
통화: JPY
```

- 스크린샷 이미지(.png)를 넣어주셔도 됩니다.
- 업로드한 파일이 **전체 캠페인**인지, **일부 캠페인**인지 꼭 적어주세요
  (일부만 내보내면 합계가 대시보드보다 작은 게 정상입니다).

## 디버깅 방법

파일과 정답지를 넣으신 뒤 알려주시면:
1. 앱이 계산한 값 vs 구글 애즈 정답지를 항목별로 비교
2. 차이가 나는 지점(중복 집계·누락·통화·필터 등)을 찾아 수정
3. 고친 내용을 배포

> 참고: 이 폴더의 파일은 앱 동작에 영향을 주지 않습니다 (분석은 브라우저 업로드로만 동작). 순수 테스트/디버깅용입니다.
