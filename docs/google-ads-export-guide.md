# 구글 애즈 내보내기 설정 가이드

이 앱이 **필요한 정보를 모두** 읽을 수 있도록, 구글 애즈에서 내보낼 때 아래 설정을 따라주세요.
(한국어/영어 헤더 모두 자동 인식, `.csv`·`.xlsx` 모두 지원, 엔화·달러는 자동 원화 환산)

---

## 0. 어떤 보고서로 뽑나

| 보고서 | 용도 | 특징 |
| --- | --- | --- |
| **광고 보고서** (메인) | 어떤 영상·소재가 조회/구독을 견인했나 | 광고(소재) 단위. **단, 삭제된 광고는 제외됨** |
| **캠페인 보고서** (보조) | 대시보드와 **정확한 총액** 맞추기 | 캠페인 단위. 삭제 광고·전환 포함 |

> 채널 분석이 목적이면 **광고 보고서**가 메인입니다. 총액을 대시보드와 100% 맞추려면 캠페인 보고서도 함께 내보내 합치세요.

---

## 1. 기간 · 범위

- **기간**: 분석할 기간 지정 (예: 2026-01-01 ~ 2026-06-05)
- **캠페인**: **전체 캠페인 모두** 선택 (일부만 빼면 합계가 대시보드보다 작아짐)
- **추출 시점**: 모든 파일을 **같은 시각**에 다운로드 (시점이 다르면 미세하게 어긋남)

---

## 2. 추가할 열 (측정항목) — 체크리스트

보고서 화면 → **열(측정항목) 수정** 에서 아래를 추가합니다.

### 필수 (기본 분석)
- [ ] 광고 이름
- [ ] 노출수
- [ ] 조회수 (TrueView 조회수)
- [ ] 클릭수
- [ ] 클릭률 (CTR)
- [ ] 비용
- [ ] **통화 코드**  ← 원화 자동 환산에 필요

### 채널 성장 (권장)
- [ ] 획득 조회수  (follow-on)
- [ ] 구독 수  (획득 구독자 = earned)
- [ ] **YouTube channel subscriptions (구독 전환)**  ← 아래 3번 참고
- [ ] 동영상 25% / 50% / 75% / 100% 재생
- [ ] 평균 시청 시간

### 세부 분석 (선택)
- [ ] 날짜
- [ ] 광고그룹
- [ ] 기기
- [ ] 연령
- [ ] 성별

---

## 3. ⭐ 구독 전환(YouTube channel subscriptions) 열 추가법

"구독 수(획득 구독자)"와 **"구독 전환"은 다른 값**입니다.
채널 성장 성과의 핵심은 **구독 전환**이므로 꼭 추가하세요.

1. 보고서 화면 → **열 수정** → **전환** 그룹
2. **전환수** 추가
3. 구독만 따로 보려면 상단 **세그먼트 → 전환 → "전환 액션"** 선택
   - 그러면 `YouTube channel subscriptions` 행이 분리되어 나옵니다
4. (또는 전환 액션이 구독 하나뿐이면 `전환수`가 곧 구독 전환)

> 처음 한 번은 이 열을 포함한 파일을 `test-data/`에 올려주세요. 실제 헤더 이름을 확인해 앱이 **구독 전환을 핵심 지표로** 쓰도록 정확히 연결해 드립니다.

---

## 4. 삭제된 광고까지 포함하기 (총액 정확도)

광고 보고서는 기본적으로 `전체: 삭제되지 않은 광고`만 집계합니다.
삭제된 광고 비용까지 맞추려면:

- 필터에서 **광고 상태 = 전체(삭제 포함)** 로 변경, 또는
- **캠페인 보고서**를 함께 사용 (캠페인 단위는 삭제 광고 포함)

---

## 5. 다운로드 & 업로드

1. 우측 상단 **다운로드** → `.csv` 또는 `.xlsx`
2. 캠페인별로 파일이 나뉘어도 OK — 앱에 **여러 개를 한꺼번에** 올리면 합산됩니다
   - 캠페인명 열이 없으면 **파일 이름이 캠페인 이름**이 되니, 파일명을 알아보기 쉽게
3. 앱( https://googleads-note.vercel.app )에 업로드 → 자동 분석

---

## 6. 자주 묻는 차이 (버그 아님)

| 증상 | 이유 |
| --- | --- |
| 합계가 대시보드보다 작음 | 일부 캠페인만 내보냄 / 삭제 광고 제외 |
| 구독이 1로 나옴 | "구독 수(earned)"를 본 것. **구독 전환** 열을 추가해야 함 |
| 획득 조회수가 매우 작음 | 정상. follow-on(덤 조회)은 원래 전체 조회의 극히 일부 |
| 금액이 ₩로 보임 | 통화 코드 열 기준 **자동 원화 환산** (환율 직접 수정 가능) |
